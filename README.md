# simple-interest-calculator
Project Description

The Simple Interest Calculator is a simple Bash-based application that calculates the simple interest based on the principal amount, annual interest rate, and time period entered by the user.

Formula

Simple Interest = (Principal × Rate × Time) / 100

Input

The calculator requires three inputs:

Principal: The initial amount of money.

Rate: The annual interest rate in percentage.

Time: The time period in years.

Output

The calculator displays the calculated simple interest based on the values provided by the user.

Example

Principal: 1000

Rate: 5%

Time: 2 years

Simple Interest: 100
